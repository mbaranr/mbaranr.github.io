# mbaranr.github.io

My personal site: plain HTML and one stylesheet. No frameworks, no JavaScript.
One small Python script (`build.py`) keeps the post lists and feed in sync.
Write, run `python3 build.py`, commit, push.

## Layout

```
index.html                  homepage (bio, post list, publications, contact)
build.py                    rebuilds the post lists and feed.xml from the posts
feed.xml                    Atom/RSS feed of posts (generated by build.py)
blog/index.html             list of all posts
blog/slug/index.html        one folder per post  ->  /blog/slug/
blog/slug/*.png             that post's images, next to it
publications/index.html     publications
bookshelf/index.html        the bookshelf: reading, read, want to read
style.css                   the only stylesheet (beige light / navy dark, follows the system)
assets/                     images shared across pages only (portrait, logos)
404.html                    not-found page
```

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Any static file server works.

## Add a post

1. Copy an existing post folder, e.g. `blog/gladgan/` to `blog/my-post/` (the folder name is
   the URL: `/blog/my-post/`), and edit its `index.html`: the `<title>`, the description and
   `og:` meta tags, the `<h1>`, the `<time datetime="...">` date, and the body.
2. Run `python3 build.py`. It rewrites the post lists in `blog/index.html` and `index.html`
   (newest 5) and the whole of `feed.xml`. Running it twice changes nothing.
3. Preview (see above), commit, push.

Figures use the `fig-row` / `fig-col` blocks documented in `style.css`; math is MathML (see below).

## Add images to a post

Put each image in the post's own folder, next to its `index.html`, and reference it with no path:
`<img src="plot.png" alt="...">`. Name files after what they show, lowercase with hyphens
(`latent-search.png`, not `fig3.png` or `Latent Search.PNG`). Only images used on several pages
(the portrait, logos) go in `assets/`. The `og:image` tag needs the full URL:
`https://mbaranr.github.io/blog/my-post/plot.png`.

Before adding an image, keep it small: the column is under 700px wide, so 1200px wide is plenty,
and aim for under ~100 KB. With ImageMagick (`brew install imagemagick`):

```sh
magick in.png -resize '1200x>' -strip out.png                 # plots, diagrams, screenshots
magick in.jpg -resize '1200x>' -strip -quality 82 out.jpg     # photos (save photos as .jpg, not .png)
```

## Add a publication

Publications use APA style, newest first, with my name in bold. Add the same `<li>` to the
`<ul class="pubs">` list in both `index.html` and `publications/index.html`. Notes such as awards
go only on the Publications page, after the DOI link:
`<br><span class="pubnote">EASST Best Paper Award.</span>`

```html
<li><b>Barandiaran, M.</b>, &amp; Coauthor, A. (2026). Title in sentence case. <i>Journal Name</i>, <i>12</i>(3), 1&ndash;20. <a href="https://doi.org/...">https://doi.org/...</a></li>
```

## Math

Write MathML by hand, which browsers render natively, e.g. `<math><mi>x</mi><mo>=</mo><mn>4</mn></math>`.
To line equations up on the `=`, use `<mtable class="aligned">` with two cells per row:
`<mtd>left side</mtd><mtd>= right side</mtd>` (see `blog/optimizing-deeprvat/`).

## Deploy

GitHub Pages serves the `main` branch root (Settings → Pages → Deploy from a branch → `main` / `/ (root)`).
The `.nojekyll` file tells Pages to serve the files as-is.
