Recoloring CIFAR-10

Created on July 15, 2023

2023   ·   code   python   pytorch   computer_vision   ·   machine_learning

I tackled the colorization task of CIFAR10 images comparing two approaches: Auto Encoders and Deep Conditional Generative Adversarial Networks (DCGANs).

Over the last decade, the process of automatic colorization has been studied thoroughly due to its potential for restoration of aged and/or degraded images. This problem is highly ill-posed due to the extremely large degrees of freedom during the assignment of color information.

I attempted to fully generalize this procedure over a publicly available dataset: CIFAR-10.

DCGAN

Similarly, the generator integrates the U-Net architecture (essentially the previous encoder) and a L1 regularized loss function, forcing output similar to the ground truth on a pixel level.

Theoretically, this will preserve the structure of the original images and prevent the generator from assigning arbitrary colors to pixels just to fool the discriminator. The generator takes the grayscaled image as an input, while the discrimator takes either the original image or generated image plus the condition, which is the grayscaled image in this case.

This concatenation is executed as such (see, repo):

  def forward(self, x):

    x1 = self.encoding_unit1(x)
    x = F.max_pool2d(x1, (2,2))

    x2 = self.encoding_unit2(x)
    x = F.max_pool2d(x2, (2,2))

    ...

    x = self.encoding_unit5(x)

    x = self.upsampling1(x)
    x = torch.cat([x, x4], dim=1)
    x = self.decoding_unit1(x)

    x = self.upsampling2(x)
    x = torch.cat([x, x3], dim=1)
    x = self.decoding_unit2(x)

    ...

    x = self.decoding_unit5(x)

    x = F.tanh(x)

    return x

Thoughts

  • DCGAN generated images had a clear visual improvement over those generated by the U-Net alone (auto encoder).

  • While the DCGAN produced vibrant images, the auto encoder suffered from a hue phenomenon called the sepia effect.

  • In some cases, the DCGAN was able to nearly replicate the ground truth. It was even able to colorize reasonably well on one of the images where the ground truth was “close” to grayscale.

  • Both models were trained for only 20 epochs. With negative gradients for the last epoch, they probably need more time to converge.
